# 蓝影论坛签到

使用蓝影论坛专用签到密钥，在 MoviePilot 中自动签到、查看实际奖励、余额和连续签到记录。

## 配置

1. 打开 [蓝影论坛](https://hdblue.cc)，在个人设置的「MoviePilot 签到」中创建设备专用密钥。密钥仅创建时展示一次，可随时撤销；不要使用论坛密码或 OAuth 客户端密钥。
2. 在 MoviePilot 添加插件仓库 `https://github.com/wzxcom/MoviePilot-Plugins`，安装「蓝影论坛签到」。V2 选择 1.x，V3 选择 2.x，由宿主自动选择对应目录。
3. 填写 `hdbmp_…` 签到密钥，开启「保存后测试连接」并保存；详情页出现正确账号后，开启自动签到。
4. 默认北京时间每天 08:30，附加 0—30 分钟随机延迟。Cron 支持五段格式，时区固定为 `Asia/Shanghai`，不受 MoviePilot 主机时区影响。

可选项：立即签到、启动后补执行当天错过的任务、仅失败/全部结果/关闭通知、指定 HTTP/HTTPS 代理。代理关闭时不读取环境代理；代理账号密码与签到密钥均以密码框输入。测试连接与立即签到同时选择时仅测试连接，两开关保存后均自动复位。

## 行为说明

- 网页签到和插件签到复用论坛同一份记录及奖励规则。重复调用不重复领奖；奖励金额与签到日期由服务器决定。
- 连接测试只查询账号与状态，打开插件详情只读本地缓存。缓存按密钥与插件实例隔离，更换密钥后清理旧账号记录。
- 网络故障最多自动重试两次，间隔 10、30 分钟；论坛限流时等待不少于 `Retry-After`。当天自动任务最多执行三轮，此预算在重启后保留。
- 请求超时且可能已签到时先查询结果再决定是否重试。401 暂停自动请求，重新填写密钥或连接测试成功后恢复；403 停止本轮重试，下个正常计划仍会查询，以支持论坛临时关闭签到后自动恢复。
- 启动补执行仅针对当天已到计划时间的任务。不补签往日，不消费补签卡；延迟或重试跨越北京时间午夜时取消该次任务。
- 关闭插件会清理待执行任务；重载后旧任务失效。运行中的 HTTP 请求有超时边界，旧配置的结果不会写入新账号缓存。
- 最近执行记录保留 30 天（最多 120 条），详情展示最近 30 条；论坛签到历史最多 30 条。通知通过 MoviePilot 已配置渠道发送，插件不另设推送服务。

## 接口与维护

固定服务地址：`https://hdblue.cc/api/integrations/moviepilot/v1`。通过 Bearer 密钥调用 `GET /me`、`GET /check-in`、`POST /check-in`（空 JSON 对象）。不跟随跳转，验证 HTTPS 证书，不输出请求头、密钥、代理或原始服务端错误正文。

协议成功响应为 `{code: 0, message, data}`，`data.protocolVersion=1`。`alreadyCheckedIn` 表示响应时的当天签到状态；`performedCheckIn` 表示本次是否执行签到。账号、奖励、余额、连续签到与历史均由论坛返回。

V2 / V3 使用相同 `core.py`，只有宿主日志导入与插件版本不同。V3 使用稳定 `app.sdk.logging`，不依赖宿主内部模块路径；无额外 Python 依赖。市场条目 `release:false` 使用源码安装，不触发插件 ZIP Release 分发。

测试位于仓库 `tests/v2/hdbluesignin` 与 `tests/v3/hdbluesignin`，不随插件安装。协议测试使用受控 HTTP 与调度器，不接触真实用户凭据；发布前还需通过真实宿主加载和论坛联调。
